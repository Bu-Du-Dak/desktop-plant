# Desktop Plant

바탕화면에 사는 작은 픽셀 식물. 할 일·집중·물·필요 없는 파일(휴지통으로)로 자라요.

이 저장소에는 설치 파일만 있어요. [Releases](../../releases/latest)에서 받으세요.

## 설치

- **Mac (Apple Silicon)**: `Desktop-Plant-<버전>-mac-arm64.dmg`
- **Mac (Intel)**: `Desktop-Plant-<버전>-mac-x64.dmg`
- **Windows**: `Desktop-Plant-Setup-<버전>-win-x64.exe`

### 처음 열 때 경고가 뜨면

- **Mac**: "확인되지 않은 개발자" → 앱을 오른쪽 클릭 → **열기** → 다시 **열기**. 또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.
- **Windows**: "Windows의 PC 보호" → **추가 정보** → **실행**.

처음 한 번만 그래요. 이후 새 버전은 앱이 알아서 받아 두었다가, 앱을 끌 때 설치해요.

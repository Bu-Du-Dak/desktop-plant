# Desktop Plant 🌱

바탕화면에 사는 작은 픽셀 식물. 할 일 · 집중 · 물 · 필요 없는 파일(휴지통으로)로 자라요.

**👉 [최신 버전 받기](../../releases/latest)**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| Mac (M1·M2·M3·M4 등 Apple 칩) | `Desktop-Plant-<버전>-mac-arm64.dmg` |
| Mac (Intel) | `Desktop-Plant-<버전>-mac-x64.dmg` |
| Windows | `Desktop-Plant-Setup-<버전>-win-x64.exe` |

> 내 Mac이 어떤 칩인지: 왼쪽 위  → **이 Mac에 관하여** → "칩"이 Apple M…이면 arm64, "프로세서"가 Intel…이면 x64

개인이 만든 앱이라 애플·마이크로소프트의 유료 인증을 받지 않았어요. 그래서 **처음 한 번** 아래처럼 경고가 떠요. 앱에 문제가 있다는 뜻이 아니라 "누가 만들었는지 확인되지 않았다"는 뜻이에요. 한 번 열고 나면 이후 업데이트는 앱이 알아서 받아요.

---

## Mac 설치

1. `.dmg`를 열고, **Desktop Plant**를 **응용 프로그램(Applications)** 폴더로 끌어다 놓아요.
2. 응용 프로그램 폴더에서 **Desktop Plant**를 실행해요.
3. *"Apple은 'Desktop Plant'에 … 악성 코드가 없음을 확인할 수 없습니다"* 창이 뜨면 **완료**를 눌러요. (**휴지통으로 이동**은 누르지 마세요)
4. **시스템 설정 → 개인정보 보호 및 보안**으로 가서, 아래쪽 **보안** 항목의
   *"'Desktop Plant'이(가) 차단되었습니다"* 옆 **그래도 열기**를 눌러요.
5. 암호(또는 Touch ID)로 확인하고, 앱을 다시 실행해 **열기**를 누르면 끝!

<details>
<summary>터미널이 편하다면 (한 줄로 끝)</summary>

앱을 응용 프로그램 폴더로 옮긴 뒤:

```
xattr -dr com.apple.quarantine "/Applications/Desktop Plant.app"
```
</details>

실행하면 Dock이 아니라 **화면 위 메뉴 막대**에 작은 식물 아이콘이 생기고, 바탕화면에 식물이 나타나요.
메뉴 막대 아이콘이 노치에 가려 안 보이면, 식물을 **오른쪽 클릭**해도 같은 메뉴가 나와요.

---

## Windows 설치

1. **다운로드할 때** 브라우저가 경고하면
   - **Edge**: 다운로드 목록에서 파일 옆 **⋯ → 유지** → *"이 앱은 확인되지 않았습니다"* 에서 **자세히 표시 → 그래도 유지**
   - **Chrome**: 다운로드 목록에서 **유지**(또는 **계속**)
2. 받은 `Desktop-Plant-Setup-….exe`를 실행해요.
3. 파란 창 *"Windows의 PC 보호"* 가 뜨면 **추가 정보**를 누르고 → 아래에 생긴 **실행** 버튼을 눌러요.
4. 설치 마법사에서 설치 위치를 고르고 **설치**를 눌러요. (관리자 권한은 필요 없어요)
5. 설치가 끝나면 바탕화면에 식물이 나타나고, 오른쪽 아래 **작업 표시줄 알림 영역**(⌃ 버튼 안쪽)에 아이콘이 생겨요.

> 백신 프로그램이 처음 보는 파일이라며 검사하거나 막을 수 있어요. 이 저장소의 릴리스에서 받은 파일이 맞다면 **허용**해 주세요.

---

## 자주 묻는 것

- **업데이트는?** 앱을 켜 두면 새 버전을 알아서 받아 두었다가, 앱을 끌 때 설치해요. 메뉴에 *"다시 시작해서 업데이트"* 가 보이면 눌러도 돼요.
- **파일을 먹이면 지워지나요?** 아니요. **휴지통**으로 옮겨질 뿐이라 언제든 되살릴 수 있어요. 먹이기 전에 항상 확인 창이 떠요.
- **식물이 마우스를 안 받아요.** "클릭 통과" 모드일 수 있어요. 메뉴 막대(작업 표시줄) 아이콘 메뉴에서 끄거나, 앱을 **한 번 더 실행**하면 꺼져요.
- **지우고 싶어요.** Mac은 응용 프로그램 폴더에서 휴지통으로, Windows는 **설정 → 앱 → 설치된 앱 → Desktop Plant → 제거**.
